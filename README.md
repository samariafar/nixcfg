## 📖 About Nixcfg

**_Nixcfg_** is the source of truth for a personal _NixOS_ workstation, capturing every aspect of the system in a single, reproducible configuration.

## 📚 Documentation

For detailed information on **_Nixcfg_** installation and usage instructions, please refer to the project's [Wiki](https://github.com/samariafar/nixcfg/wiki). The Wiki provides comprehensive guides and resources to help you get started with **_Nixcfg_** and make the most out of its features. Additionally, you can find answers to the most frequently asked questions (FAQs) in the Wiki.
